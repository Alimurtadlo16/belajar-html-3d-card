3D Interactive Card Exploration - HTML & CSS
---
This repository contains the source code and design implementation for an interactive 3D Card project built using HTML and advanced CSS techniques. The project focuses on creating a visually striking, dynamic user interface component that responds seamlessly to user interaction, exploring modern front-end styling capabilities.

📌 Project Status: ✅ Completed (Maintained)
The 3D card layout and animation effects have been successfully completed and tested. This repository serves as a practical web design portfolio piece and a reference for advanced CSS transformation logic.

🚀 Key Features & Design Techniques
Within this project, the core focus was directed towards mastering depth and interaction in web design, including:

3D Transform Effects: Utilising CSS properties such as transform-style: preserve-3d;, perspective, and rotateY/rotateX to create genuine depth.

Smooth Hover Animations: Implementing fluid transition effects that bring the card to life when hovered over by the user.

Layered Elements: Structuring HTML elements to pop out or shift independently within the 3D space for an immersive parallax effect.

Fully Responsive Design: Ensuring the card scales gracefully and maintains its visual appeal across desktop, tablet, and mobile displays.

🛠️ Technologies Used
Mark-up Language: HTML5

Styling & Animation: CSS3 (Custom properties, 3D transforms, and transitions)

IDE/Editor: Visual Studio Code

Version Control: Git & GitHub
💻 How to View the Project Locally
Prerequisites
To view and interact with this project, all you need is a modern web browser (such as Google Chrome, Mozilla Firefox, Safari, or Microsoft Edge).

Steps to Run
Clone this repository to your local machine:

```Bash
git clone https://github.com/Alimurtadlo16/belajar-html-3d-card.git
```

Navigate into the project directory:

```Bash
cd belajar-html-3d-card
```

Open the index.html file in your preferred web browser:

Simply double-click the index.html file in your file explorer, or

Use an extension like Live Server in Visual Studio Code for a live preview.
